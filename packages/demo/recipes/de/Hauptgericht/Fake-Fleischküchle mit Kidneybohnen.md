## Zutaten

| Menge           | Zutat |
|-----------------|-------|
| 1 mittlere      | Zwiebel |
| 1 Zehe          | Knoblauch |
| 10 g            | Petersilie |
| 10 g            | Majoran |
| 50 g            | Walnusskerne |
| 2 Dosen à 285 g | Kidneybohnen |
| 2 EL            | Senf |
| 65 g            | Haferflocken |
| 3 EL            | Semmelbrösel |
| 2               | Eier |
| 2 EL            | Olivenöl |
| 80 ml           | Milch |
| 3 EL            | Butterschmalz |
|                 | Salz, Pfeffer |

## Zubereitung

1. Haferflocken in etwas Milch mind. eine halbe Stunde ziehen lassen.
2. Zwiebel und Knoblauch schälen, fein schneiden, Petersilie fein hacken (oder getrocknete nehmen). Walnusskerne fein hacken. Zwiebeln, Knoblauch und Petersilie in etwas Fett andünsten, später Walnüsse dazugeben.
3. Kidneybohnen in einem Sieb abgießen, waschen und abtropfen lassen. Portionsweise in eine Schüssel geben und mit einem Löffel gut zerdrücken.
4. Alle Zutaten dazugeben und alles vermischen. Mit Salz und Pfeffer gut würzen und wie Fleischküchle mit der Hand formen.
5. Butterschmalz in der Pfanne erhitzen und die Küchle von beiden Seiten auf mittlerer Hitze goldbraun anbraten.

## Tipps

- Variation eines Rezepts von Rewe.
