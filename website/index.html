The home dashboard for the screen in your kitchen

Culinola is a self-hosted smart home dashboard for a wall tablet or kitchen display. It brings your house, your media and your family's day together on one touch screen – arranged the way you want, set up entirely in the browser.

This is not a screenshot. It is Culinola itself, running in your browser with the layout of the kitchen it was built for. Go ahead and tap: play the radio, set the egg timer on the clock, switch the lights, tick off the shopping list, open a recipe.

Real

The interface, the layout editor and the setup pages. Radio streams live from the stations, news come live from Deutsche Welle, sun and moon are calculated, the recipes are from our family cookbook.

Made up

Readings, switches, appointments, calls, e-mails and the shopping list are invented. The cameras show recordings of our front door and garden on a loop. Voice control understands only a few fixed sentences.

Yours alone

There is no server behind the demo – it runs entirely in your browser. What you change stays in this browser and nobody else sees it. “Start over” brings back the original.

Why Culinola

Everything at a glance

No scrolling, no menus: a grid of tiles that fills the display and scales with it.

Works with what you have

openHAB, Home Assistant, Homematic, MQTT, FRITZ!Box, IMAP, Google Calendar, RSS, cameras via go2rtc – each one is a plugin.

Set up in the browser

Drag tiles into place, pick datapoints from a searchable list, add sources and credentials. Displays pick up every change without a restart.

More than a smart-home panel

Internet radio and live TV, your cameras, the newest e-mails, calls from the FRITZ!Box and an egg timer on the clock are built in.

Made for the whole family

An egg timer on the clock, recipes to cook from, ingredients onto the shopping list, a doorbell message with the camera behind it.

Yours

Runs on your own hardware in your own network. The source is open to read and change, and free for private and other noncommercial use.

One API for everything

The interface uses the same HTTP and WebSocket API as any other program. A setup password protects it; displays are paired by a code they show, programs get a token.

A look around

The light theme shows a real installation; calls, e-mails, appointments and reminders in it are made up. The setup pages show the built-in test instance.

Get started

You need Node.js 22.18 or newer.

git clone https://github.com/achrista/culinola.git
cd culinola
npm install
npm run build
npm start

Open http://localhost:8090. Without a configuration of your own, Culinola starts with made-up demo values. Add ?layout=main&edit to the address to open the layout editor.

Culinola itself needs nothing but Node.js. Cameras and live TV additionally need the separate programs go2rtc and, for streams that have to be converted, ffmpeg; the wake word needs a Vosk speech model; voice commands and adding recipes from photos need a Claude API key – no subscription, just prepaid credits from platform.claude.com, starting at about US$5. The Docker image already contains go2rtc and ffmpeg.

Culinola is young: expect rough edges, and please report them on GitHub. The interface is available in German and English.
