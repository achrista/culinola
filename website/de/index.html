Das Haus-Dashboard für den Bildschirm in Ihrer Küche

Culinola ist ein selbst betriebenes Smart-Home-Dashboard für ein Wand-Tablet oder Küchendisplay. Es bringt Ihr Haus, Ihre Medien und den Tag der Familie auf einem Touch-Bildschirm zusammen – so angeordnet, wie Sie es möchten, und komplett im Browser eingerichtet.

Live ausprobieren Loslegen Auf GitHub ansehen

LiveGleich hier ausprobieren

Das ist kein Bildschirmfoto. Das ist Culinola selbst, es läuft in Ihrem Browser, mit dem Layout der Küche, für die es entstanden ist. Tippen Sie ruhig: Radio einschalten, die Eieruhr an der Uhr stellen, Licht schalten, die Einkaufsliste abhaken, ein Rezept öffnen.

Beim Start lädt die Demo aktuelle Nachrichten von DW, Augsburger Allgemeine und tagesschau in Ihren Browser; Radiosender werden erst angesprochen, wenn Sie einen wählen. Mehr in der Datenschutzerklärung.

Die Küchenanzeige ist für einen großen Bildschirm gemacht – im Vollbild lässt sie sich richtig ausprobieren.

Im Vollbild öffnen Layout-Editor ausprobieren

Echt

Die Oberfläche, der Layout-Editor und die Einrichtungsseiten. Das Radio kommt live von den Sendern, die Nachrichten live von DW, Augsburger Allgemeine und tagesschau, Sonne und Mond sind berechnet, die Rezepte stammen aus unserem Familienkochbuch.

Erfunden

Messwerte, Schalter, Termine, Anrufe, E-Mails und die Einkaufsliste sind ausgedacht. Die Kameras zeigen Aufnahmen von unserer Haustür und unserem Garten in Schleife. Die Sprachsteuerung versteht nur ein paar feste Sätze.

Nur für Sie

Hinter der Demo steht kein Server – sie läuft ganz in Ihrem Browser. Was Sie ändern, bleibt in diesem Browser, und niemand sonst sieht es. „Von vorn beginnen“ stellt den Ausgangszustand wieder her.

Warum Culinola

Alles auf einen Blick

Kein Scrollen, keine Menüs: ein Raster aus Kacheln, das den Bildschirm füllt und mit ihm skaliert.

Arbeitet mit dem, was Sie haben

openHAB, Home Assistant, Homematic, MQTT, FRITZ!Box, IMAP, Google Kalender, RSS, Kameras über go2rtc – jedes davon ist ein Plugin.

Im Browser eingerichtet

Kacheln an ihren Platz ziehen, Datenpunkte aus einer durchsuchbaren Liste wählen, Quellen und Zugangsdaten hinzufügen. Die Anzeigen übernehmen jede Änderung ohne Neustart.

Mehr als ein Smart-Home-Panel

Internetradio und Live-Fernsehen, Ihre Kameras, die neuesten E-Mails, Anrufe von der FRITZ!Box und eine Eieruhr an der Uhr sind eingebaut.

Für die ganze Familie

Eine Eieruhr an der Uhr, Rezepte zum Nachkochen, Zutaten direkt auf die Einkaufsliste, eine Türklingel-Meldung mit dem Kamerabild dahinter.

Ihr eigenes

Läuft auf Ihrer eigenen Hardware in Ihrem eigenen Netz. Der Quelltext ist offen einsehbar und veränderbar, und frei für die private und sonstige nicht kommerzielle Nutzung.

Eine Schnittstelle für alles

Die Oberfläche nutzt dieselbe HTTP- und WebSocket-Schnittstelle wie jedes andere Programm. Ein Einrichtungskennwort schützt sie; Anzeigen werden über einen Code gekoppelt, den sie selbst zeigen, Programme bekommen ein Token.

Ein Blick hinein

Das helle Farbschema zeigt eine echte Installation; Anrufe, E-Mails, Termine und Erinnerungen darin sind erfunden. Die Einrichtungsseiten zeigen die eingebaute Testinstanz. Die Bildschirmfotos zeigen die englische Oberfläche; Culinola gibt es auch auf Deutsch.

Loslegen

Sie brauchen Node.js 22.18 oder neuer.

git clone https://github.com/achrista/culinola.git
cd culinola
npm install
npm run build
npm start

Öffnen Sie http://localhost:8090. Ohne eigene Konfiguration startet Culinola mit erfundenen Beispielwerten. Hängen Sie ?layout=main&edit an die Adresse, um den Layout-Editor zu öffnen.

Culinola selbst braucht nichts außer Node.js. Kameras und Live-Fernsehen brauchen zusätzlich die getrennten Programme go2rtc und, für Streams, die umgewandelt werden müssen, ffmpeg; das Aktivierungswort braucht ein Vosk-Sprachmodell; Sprachbefehle und das Hinzufügen von Rezepten aus Fotos brauchen einen Claude-API-Schlüssel – kein Abo, nur Guthaben im Voraus von platform.claude.com, ab etwa 5 US-Dollar. Das Docker-Image enthält go2rtc und ffmpeg bereits.

Culinola ist jung: Rechnen Sie mit Ecken und Kanten und melden Sie sie bitte auf GitHub. Die Oberfläche gibt es auf Deutsch und Englisch.
